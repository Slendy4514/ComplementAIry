# Qué busca este proyecto

<!-- Escribí con tus palabras. La IA lo lee en cada guía y revisión. Ejemplos de qué poner: -->

AICode es un proyecto que usa estrategias estudiadas y comprobadas para que el usuario programe y comprenda el proyecto que está creando a la vez que se beneficia del uso de la IA para programar de forma veloz

<!-- - Para qué sirve y para quién es. -->

Este proyecto inicialmente está pensado para programadores, pero también se extenderá a usuarios no técnicos.

<!-- - Qué es lo más importante -->

La IA no toca código de entrada, sino que guia al usuario mediante comentarios. Le ayuda a crear las funciones y la IA solo puede programar con lo que ya se corroboró antes.
